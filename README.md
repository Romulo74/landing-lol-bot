## Landing Page do Bot de League of Legends

Esta é a página de apresentação do Bot de League of Legends, projetado para interagir com os fãs do jogo através do Telegram.

## Funcionalidades:
- Fala icônica dos campeões do League of Legends
- Quiz sobre o jogo e suas mecânicas
- Visualização do placar de acertos e erros

Acesse o bot no Telegram para interagir com ele!

## Link da Landing Page

Acesse nossa landing page publicada pelo GitHub Pages:  
[https://seu-usuario.github.io/landing-page-bot-lol/](https://seu-usuario.github.io/landing-page-bot-lol/)

## Como usar o bot:
1. Abra o Telegram e busque pelo bot.
2. Utilize os comandos disponíveis como `/frase [campeao]`, `/quiz`, e `/placar`.
